# Lion App — Organizador de Dados para Imposto de Renda (Excel)
 
## Sobre o projeto
 
Este projeto tem como objetivo criar uma ferramenta no Excel que ajude a organizar e reunir informações essenciais para a declaração de imposto de renda.
 
A proposta é construir um **agregador de dados** no qual o usuário possa controlar suas entradas de maneira eficiente e validada, com menus de navegação, validações automáticas e funcionalidades extras, como links rápidos.
 
A solução será **completamente construída no Excel**, com recursos que tornam a ferramenta robusta, mas com uma interface amigável e prática.
 
## Objetivos
 
- Centralizar em um único arquivo as informações necessárias para a declaração.
- Garantir a qualidade dos dados com validações automáticas na entrada.
- Oferecer uma navegação simples, em formato de aplicativo, dentro do Excel.
- Facilitar o acesso rápido a informações e recursos externos por meio de links.
- Reduzir erros e esquecimentos na hora de preencher a declaração.
## Estrutura da ferramenta
 
A navegação é feita por um menu lateral, com botões **Anterior** e **Próximo** para conduzir o preenchimento passo a passo.

## Funcionalidades
 
- **Menu de navegação** lateral com destaque para a aba ativa.
- **Botões Anterior / Próximo** para seguir o fluxo de preenchimento.
- **Validações automáticas** (por exemplo: CPF, datas, CEP, e-mail, listas de bancos).
- **Cálculo automático de totais**.
- **Links rápidos** para anexos e para sites úteis.
- **Interface amigável**, com campos destacados para preenchimento e identidade visual própria.
## Tecnologias
 
- Microsoft Excel
  - Fórmulas e validação de dados
  - Formatação condicional
  - Hiperlinks
  - Formas e botões de navegação
